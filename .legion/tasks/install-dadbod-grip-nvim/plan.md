# install-dadbod-grip-nvim

## 目标

Install dadbod-grip.nvim in the existing LazyVim/lazy.nvim Neovim configuration so Parquet files can be opened and explored inside Neovim via DuckDB-backed commands.

## 问题陈述

The current Neovim config has no Parquet-aware viewer plugin. The user wants dadbod-grip.nvim installed through the Legion workflow after evaluating it as the strongest in-editor Parquet option.

## 验收标准

- [ ] A lazy.nvim plugin spec for joryeugene/dadbod-grip.nvim exists under lua/plugins and can be discovered by the existing plugins import.
- [ ] Useful keymaps or command access are available without replacing existing plugin configuration patterns.
- [ ] The installation is verified far enough to confirm Neovim can load the updated configuration, or any external dependency gap is documented.

## 假设 / 约束 / 风险

- **假设**: The repository uses LazyVim with lazy.nvim and imports lua/plugins/*.lua.
- **假设**: This task installs the Neovim plugin only; DuckDB CLI availability is verified or reported, not installed as a system package without explicit request.
- **约束**: Keep the change minimal and avoid broad LazyVim restructuring.
- **约束**: Do not enable destructive file write-back workflows by default.
- **约束**: Out of scope: installing system packages, configuring AI providers, enabling default write mode, or building a custom Parquet buffer hijack.
- **风险**: dadbod-grip requires DuckDB CLI for Parquet workflows; plugin installation alone may not make Parquet viewing usable if duckdb is missing.
- **风险**: Plugin commands may lazy-load but health checks can still depend on external CLIs.

## 要点

- **LazyVim 插件入口**: 在 `lua/plugins/` 下新增独立 spec，让现有 `{ import = "plugins" }` 自动发现。
- **安全默认值**: 只安装和暴露常用查看/查询入口，不默认开启 `--write` 或任何会覆盖数据文件的流程。
- **Parquet 依赖边界**: `dadbod-grip.nvim` 依赖 DuckDB CLI 处理 Parquet；本任务验证并记录依赖状态，但不安装系统包。
- **验证策略**: 用 headless Neovim 加载配置，并检查插件命令/外部依赖是否达到可用状态。
