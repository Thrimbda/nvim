What Changed / What Was Decided

本任务删除下面这段本地覆盖，让 orgmode refile 回到默认 input completion。

ui = {
  input = {
    use_vim_ui = true,
  },
},

这个决定保留 orgmode.nvim 上游 Capture:get_destination() 与 Capture:autocomplete_refile() 行为，避免复制 refile 解析和移动逻辑。
