Reviewer Summary

  • Archive 缺项根因是配置层只把 DONE/CANCELLED 当完成态，未把 capture templates 中已有的 PHONE/MEETING 纳入 done keyword 集合。
  • Warning 重复根因是 refresh_all() 自己通知一次，agenda wrapper 又按 fail 数通知一次，而且 wrapper 没有文件级失败详情。
  • 本轮不同于 PR #11 的 section order/virtual tag 展示，也不同于 PR #12 的 archive matcher/月度窗口。这里补的是 done keyword parity 和 refresh diagnostics。
  • 当前验证结论为 PASS，真实 agenda 文件 refresh 输出 total=22 ok=22 fail=0 skipped_conflict=0 skipped_unloaded=0。
