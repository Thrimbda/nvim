What Changed / What Was Decided

  • `b` custom command 改为 Norang-style block agenda，并移除旧的 `Today` overriding header。
  • `REFILE` 区标题改为 `Tasks to Refile`，archive 区标题改为 `Tasks to Archive`。
  • WAITING 和 HOLD 合并为 `Waiting and Postponed Tasks`。
  • 新增 `PROJECT_TASK` 虚拟标签，并把 `PROJECT/STUCK/PROJECT_TASK/ARCHIVE_CANDIDATE` 排除出 tag inheritance。
  • `OrgLegionRefresh` 只重建内存索引；agenda/search 查询虚拟标签时临时注入分类，不写回 org 文件。
  • ``、`oab`、`oan`、`oas` 打开 agenda 前会先执行 `org_legion.refresh_all()`。
